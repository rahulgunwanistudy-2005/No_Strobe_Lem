# Session 7 — AWS pipeline + open-source `hazardtrack` repo

Read `CLAUDE.md` (§17, §18), `tasks/lessons.md`. Plan first. Watch costs: use the hackathon AWS credit, tear down when idle.

## Goal
Drop an MP4 into S3 `ingest/` → minutes later the TV app's catalog shows it with verified HazardTracks for all profiles and a public report. Separately, a public Apache-2.0 repo `hazardtrack` holds the spec + reference library + web reader.

## Build — AWS
1. **Container** (`infra/lambda/Dockerfile`): AWS Lambda Python 3.12 base image, static ffmpeg/ffprobe (pinned release, checksum verified), `nostrobe` installed from the wheel built in CI. Image size budget < 1 GB.
2. **Handler** (`infra/lambda/handler.py`, thin): parse S3 event → download to `/tmp` (stream) → `probe` (reject non-SDR → write `public/{id}/status.json` with error) → `analyze` all profiles → upload video + tracks + report to `public/{id}/` → rebuild `public/catalog.json` by listing `public/*/status.json` (idempotent). `content_id` = first 12 hex of source SHA-256 + slugified name.
3. **SAM template** (`infra/template.yaml`): bucket (block public access except a policy granting `s3:GetObject` on `public/*` only), Lambda (memory 3008 MB, timeout 900 s, ephemeral storage sized for inputs, reserved concurrency 2), S3 notification on `ingest/` suffix `.mp4`, log retention 7 days, least-privilege IAM (read `ingest/*`, write `public/*`). CORS on `public/*` for GET only. Outputs: catalog URL.
4. **Ops** — structured JSON logs with `content_id`, duration, per-profile event counts, verifier result; failures write `status.json` with a typed error; no PII.
5. **`docs/AWS.md`** — architecture diagram (ASCII), deploy (`sam build && sam deploy --guided`), teardown (`sam delete` + bucket empty), measured cost per analyzed hour of video and Lambda × real-time. These numbers come from real runs; record them in RESULTS.md too.
6. Point `tv/src/config.ts` at the catalog URL (build-time config), smoke-test end-to-end on the VVD.
7. If Kiro was used during development, document how in `docs/AWS.md` (it independently qualifies for the AWS Builder mini challenge per rules); never claim usage that didn't happen.

## Build — Open source
8. Create public repo **`hazardtrack`** (Apache-2.0, LICENSE visible in About), new during the hackathon window: `spec/HAZARDTRACK.md` (format, playback semantics, conformance fixture), `schema/`, Python reference library (detector + verifier + writer/reader; no AWS, no TV code), `examples/web/` (HTML5 `<video>` + metadata-track reader that applies the veil with a CSS overlay — 40–80 lines, works in desktop Chrome/Firefox), `CONTRIBUTING.md`, CI (ruff, mypy, pytest, schema drift).
9. The product repo depends on the published library (git tag or PyPI test index). Record for the form: contribution URL, repo URL, GitHub username, 3-sentence what/how/why.

## Acceptance gates
- `sam deploy` from clean checkout works; upload a CC-BY clip → catalog updated with 3 verified tracks within the measured time; TV app shows it.
- Bucket policy test: `ingest/` objects not publicly readable (curl 403); `public/` readable.
- `hazardtrack` repo CI green; web example demonstrably veils a synthetic clip (record a short screen capture of traces/overlay only — no raw strobe).
- Teardown documented and tested once.
