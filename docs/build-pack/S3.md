# Session 3 — Veil solver, closed-loop verifier, HazardTrack writer, CLI, report

Read `CLAUDE.md`, `tasks/lessons.md`, `docs/INTERPRETATIONS.md`. Plan first.

## Goal
`nostrobe analyze video.mp4 --out dir/` writes, for each profile, a HazardTrack (`.hzt.json` + `.hzt.vtt`) whose veils are the minimum-distortion veils that make every segment pass the detector under ±sync tolerance — or the segment is explicitly marked unresolved. Plus a human report.

## Build
1. **`veil/composite.py`** — `apply_veil(luma_code_norm, rgb_norm, alpha, gray) -> (luma', rgb')` per bible §13, plus `veil_timeline(cues, t) -> (alpha, gray)` implementing ramps exactly as the TV scheduler will (shared semantics: write them down in `spec/HAZARDTRACK.md` §Playback semantics so S5 implements the same function). Tests: α=0 identity; α=1 → flat gray; ramps linear and continuous; out-of-range rejected.
2. **Segmenting** — pad events by lead/tail, merge within `merge_gap_s`, clamp to [0, duration]. Tests incl. overlapping/adjacent events and events at t=0 / end.
3. **`verify/verifier.py`** — `verify(path, cues, profile, offsets) -> VerifierResult`: re-decode (or reuse cached cell arrays — cache luma cells + RGB cells per file in a memory-mapped `.npy` keyed by `source_sha256`, so solve/verify loops don't re-decode), apply the veil timeline shifted by each offset, re-run the full detector, collect residual `fail` events.
4. **`veil/solver.py`** — per segment, search `gray_candidates × α grid` (coarse 0.02 steps, then bisection to 0.005) for minimum mean |ΔL| subject to segment-local verifier pass at all offsets (segment-local = verify the segment plus 1.5 s context each side, for speed; the final full-file verify in step 5 is the authority). Unresolved → bible §13 behaviour. Deterministic tie-breaking (lower α, then lower gray).
5. **Full-file verification** after solving; if any residual `fail`, iterate solver on those segments once; if still failing, mark unresolved. Publishing refuses `passes=false` (writes `*.unresolved.hzt.json` only).
6. **`track/jsonio.py` + `track/webvtt.py`** — writer and reader per bible §15; round-trip tests; WebVTT validates against a strict parser (write a minimal one; also test with a known WebVTT library if available). Timestamps formatted `HH:MM:SS.mmm`, cues non-overlapping-safe (WebVTT allows overlap; still sort by start).
7. **Stats** — veiled fraction of runtime, mean α, mean |ΔL| cd/m², events by kind.
8. **CLI** — `analyze` (all profiles by default, `--profile` to limit), `verify` (re-verify an existing track against a video), `report` (HTML), `schema`. Exit codes: 0 ok, 2 unresolved segments present, 3 unsupported media, 4 decode error. One-line errors, JSON logs to stderr.
9. **`report/html.py`** — single static HTML (Jinja2, inline CSS, inline PNG charts via matplotlib Agg): media info, per-profile event table, luminance trace of the max-hot cell group per event **before vs after veil** (traces only, never frames of raw hazards), veil timeline, verifier result, params hash, disclaimer (bible §5).

## Acceptance gates
- Quality gates clean.
- On the full synthetic suite: **verifier passes = 100% of must-fail clips at offsets {−tol, 0, +tol}**, or the clip's segments are marked unresolved with the reason; must-pass clips get zero veils.
- Viewing cost on must-fail clips reported (mean α, mean |ΔL|); no veil applied outside padded hazard segments (test).
- `nostrobe analyze` on a 10-min film completes; time recorded.
- JSON ↔ WebVTT round-trip lossless for veils; schema test still green.
