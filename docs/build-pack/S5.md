# Session 5 — Vega app core: W3C player, veil layer, drift-corrected scheduler, on-device calibration

Read `CLAUDE.md`, `tasks/lessons.md`, `spec/HAZARDTRACK.md` (Playback semantics). Plan first. Use the Amazon Devices Builder Tools MCP for Vega API questions where available; note what helped in `docs/PRODUCT_FEEDBACK.md`.

## Goal
A Vega app on the Vega Virtual Device that plays a catalog video, loads its HazardTrack, and drives a gray veil whose timing and compositing are measured, with the measured sync tolerance fed back into the engine.

## Build
1. **Project** — generate a fresh React Native for Vega app in `tv/` with the current Vega CLI template (TypeScript strict). Add `@amazon-devices/react-native-w3cmedia`. Copy patterns, not files, from `vega-video-sample` unless its license allows reuse (check and record). Generate `src/types/hazardtrack.ts` from the JSON Schema; add `npm run gen:types` and a test that fails on drift.
2. **`player/PlayerAdapter.ts`** (interface) and **`player/VegaW3CPlayer.ts`** — `VideoPlayer` created once, `await initialize()` before `src`, surface handle from `KeplerVideoSurfaceView` `onSurfaceViewCreated` → `setSurfaceHandle`, clean teardown (`clearSurfaceHandle`, `deinitialize`) on unmount. Subscribe to `timeupdate`, `seeked`, `play`, `pause`, `ratechange`, `ended`, `error`. Typed errors surfaced to UI.
3. **`veil/mediaClock.ts`** — bible §16.2, pure TS; inject `now()` for tests. Jest tests: steady playback interpolation, pause hold, seek re-anchor, rate 1.5×, drift correction on large discrepancy.
4. **`veil/scheduler.ts`** — implements the exact `veil_timeline` semantics from the spec (same ramps as `veil/composite.py`). Write a **shared conformance fixture**: the engine exports `spec/examples/timeline_conformance.json` (cues + 500 sample times + expected (alpha, gray)); jest asserts the TS scheduler matches within 1e-6. Seek-into-veil and end-of-media cases included.
5. **`veil/VeilLayer.tsx`** — absolute-fill `View` above the video surface; background gray from cue; opacity driven per frame (rAF loop) from scheduler(mediaClock.now()). Try native-driven `Animated` first; if unsupported on Vega, fall back to JS-driven updates and log it in friction/product feedback with evidence.
6. **`track/load.ts`** — fetch `.hzt.json` (canonical); validate against generated types + runtime guard (reject `verifier.passes=false`); WebVTT reader kept for spec portability tests only.
7. **Minimal screen** — hard-coded single catalog item (local dev server or S3 URL from `config.ts`) to prove the loop.
8. **Sync calibration (critical, produces a number the engine needs):**
   - Engine generates a **calibration clip** (not hazardous): a frame counter burnt in large digits + a corner patch that turns white for exactly 1 frame at known times, plus a HazardTrack whose veils switch a contrasting gray at those same times (instant cues with zero ramp, calibration-only, flagged so they never ship).
   - Record the VVD screen (OS screen recorder or `ffmpeg -f avfoundation|x11grab`) at ≥ 60 fps while playing; script `tools/measure_sync.py` reads the recording, finds patch flashes and veil switches, computes offset distribution (median, p95, max). Repeat with seeks and pause/resume.
   - Write `eval/sync_calibration.json`; set `params.sync_tolerance_s = max(p95 × 1.5, 0.1)`; re-run S3/S4 so all tracks verify at the measured tolerance. Record that RESULTS.md headline now cites the measured value.
9. **Compositing calibration:** play gray ramps (codes 16…235) with veils at α ∈ {0.25, 0.5, 0.75} and g ∈ {0, 0.25, 0.5}; capture; compare measured output code with `y_out = (1-α)y + αg`; fit and write `eval/compositing_calibration.json`. If the error > 2 codes, update `veil/composite.py` to the measured model and re-run S4.

## Acceptance gates
- `npx tsc --noEmit`, eslint, jest clean; app builds and runs on the Vega Virtual Device; plays a CC-BY clip with its veils.
- Scheduler conformance fixture passes (TS == Python within 1e-6).
- `eval/sync_calibration.json` and `eval/compositing_calibration.json` exist with real measurements; engine re-verified at the measured tolerance; S4 gates still pass.
- No Vega imports outside `player/` (lint rule or test).
