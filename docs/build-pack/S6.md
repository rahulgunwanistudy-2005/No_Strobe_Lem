# Session 6 — Vega UX: catalog, profiles, hazard-ahead chip, scrubber map, settings (and Lane B only if needed)

Read `CLAUDE.md` (§5 copy rules, §14 safety, §16), `tasks/lessons.md`. Plan first. Consult Amazon's Vega TV UI patterns (focus management, D-pad navigation) via docs or the Builder Tools MCP.

## Goal
A complete, D-pad-only product experience that a judge understands in 10 seconds: pick a title, it just plays safely; flashing segments are veiled; you can see where hazards are and skip them; Kids is automatic.

## Build
1. **Catalog** — reads `catalog.json` (from `config.ts` base URL): grid of titles with poster, duration, and a small badge showing hazard count for the active profile ("2 flashing segments softened"). Focus ring visible; initial focus on first item; back button behaviour correct.
2. **Profiles & Settings** — Broadcast / Local / Kids; "Warn me before hazards" toggle; disclaimer (exact text bible §5); attribution screen for CC-BY sources. Persist with the Vega-supported storage API (verify which; log friction if unclear). Profile change reloads the matching track without restarting playback (seamless swap at next frame).
3. **HazardAheadChip** — appears 3 s before any veil (if warn toggle on) and always before `unresolved` segments: "Flashing ahead · OK to skip". OK seeks to the segment end + tail; chip announces via accessibility label. Never covers the veil logic (veil still applies if the user doesn't skip).
4. **HazardScrubber** — custom progress bar on D-pad left/right seek; ticks: red = veiled segment, amber = warn-only, striped = unresolved. Seeking into a veil snaps the veil to full strength (scheduler handles).
5. **Player chrome** — title, profile pill, elapsed/remaining, the scrubber; auto-hide after 4 s; shown on any D-pad input.
6. **Empty/error states** — track missing (play with a visible "Not analyzed — no protection" banner and a default-to-pause prompt for Kids), track invalid/`passes=false` (refuse protected mode, explain), network error (retry), unsupported media.
7. **Performance** — measure app start-to-first-frame and focus-move latency on the VVD; no frame drops from the rAF veil loop (check with Vega's performance tooling if available; log what you used).
8. **Lane B (only if Lane B was chosen in S1)** — `ReactNativeVideoPlayer` adapter for the Android TV emulator; same UI; document differences.

## Acceptance gates
- Every flow is completable with D-pad only on the VVD: launch → catalog → play → chip → skip → settings → profile swap → back.
- jest tests for chip timing logic, scrubber tick mapping, profile swap state machine.
- Copy audit: grep the app for forbidden phrases in bible §5 → zero hits.
- Release build excludes raw mode (test or build-flag check).
- tsc/eslint/jest clean; app runs on VVD.
