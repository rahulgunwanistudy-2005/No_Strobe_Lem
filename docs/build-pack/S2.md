# Session 2 — Detection engine (luma flash, red flash, extended, area, profiles)

Read `CLAUDE.md`, `tasks/lessons.md`, `docs/INTERPRETATIONS.md`. Plan in `tasks/todo.md` first.

## Goal
`nostrobe analyze --detect-only` turns a video into `HazardEvent`s per profile, exactly per bible §4/§11/§12, proven by boundary and property tests, with zero missed hazards on the S1 must-fail clips.

## Build
1. **Re-read the sources** (BT.1702-3 §§ on flashes, red, area, the 9-frame note; Ofcom note). If anything in bible §4 deviates from the text, fix the code to the text and add a lesson.
2. **`detect/zigzag.py`** — `ChangeDetector(shape, thr_fn)`: `update(L: float32[90,160], t: float) -> bool[90,160]` (cells registering a change this frame); per-cell running extreme + direction; ring buffer of change timestamps (fixed capacity, e.g. 64) per cell. Fully vectorized; no Python loops over cells. Unit tests: monotone ramp registers changes only at threshold crossings; square wave at ΔL=21 registers every edge; ΔL=19 none; regime switch around 160 uses `thr` correctly; noise (σ=3 cd/m²) on a flat field registers none.
3. **`detect/luma_flash.py`** — per frame: changes in trailing 1-s window per cell, after applying the leading-edge spacing rule (bible §4.5) — implement as: pair consecutive changes into flashes; a flash whose leading edge is ≥ 0.36 s after the previous flash's leading edge does not count toward the rate. Output per-cell hot mask (count > profile limit).
4. **`detect/red_flash.py`** — saturated-red state per cell from RGB cells (linearization per your S1 interpretation), red change = state transition with Δu′v′ > 0.2; same counting/hot mask.
5. **`detect/area.py`** — `global_fraction(mask)`; `max_local_fraction(mask, win=(30,53))` via summed-area table. Tests: synthetic masks with known answers incl. window at the borders.
6. **`detect/events.py`** — hazardous frame flags → intervals (`t_start` = first hazardous frame pts, `t_end` = last + 1 frame); merge per `merge_gap_s`; compute peak stats; `warn` intervals per bible §11.
7. **`detect/extended.py`** — per Ofcom note, warn-only.
8. **Pipeline** `analyze_detect(path, profile) -> list[HazardEvent]` wiring decode → cells → detectors → area → events. Single pass over the file computing all three profiles at once (they share change detection; only counts/area differ).
9. **Performance:** benchmark on a 10-min 1080p CC-BY film; target ≥ 20× real-time per core for detection. Profile and fix hot spots before moving on.
10. **Tests:**
    - Every S1 boundary pair behaves as truth says, for each fps in {24,25,30,50,60}.
    - Interval IoU ≥ 0.9 vs truth on must-fail clips.
    - Hypothesis property tests: (a) scaling all luminance differences down below 20 cd/m² in the dark regime never produces luma events; (b) adding isolated ≤3 flashes to any clip never adds a `fail`; (c) detector output is invariant to clip resolution changes (720p vs 1080p of the same synthetic content) within ±1 frame.
    - Must-fail clips produce ≥ 1 `fail` event in **every** profile where the truth says fail (kids may add more, never fewer).

## Acceptance gates
- All quality gates clean (ruff, mypy --strict, pytest).
- **Missed hazards (FN) on the must-fail synthetic set = 0** for all profiles. False alarms on must-pass set reported; target 0; any non-zero is investigated and either fixed or justified in `docs/INTERPRETATIONS.md`.
- Speed benchmark recorded in `tasks/todo.md` with machine specs.
- Friction log updated with anything real (ffmpeg flags, ITU PDF quirks, etc.).
