# Session 1 — Scaffold, contracts, BT.1702 luminance model, synthetic generator

Read `CLAUDE.md` fully, then `tasks/lessons.md` if it exists. Follow the engineering-workflow gates. Write the plan to `tasks/todo.md` before any code.

## Goal
A monorepo that type-checks, lints and tests clean, with every contract defined, the BT.1702 SDR luminance model transcribed and tested, a seeded synthetic hazard-clip generator, and the dev-environment lane decided.

## Build
1. **Lane decision first.** Report host OS/arch. If macOS ≥ 10.15 or Ubuntu ≥ 20.04: install the Vega CLI per Amazon's current install doc, run `vega --version`, `vega virtual-device start`, run the stock hello-world on the Vega Virtual Device, stop it. Record versions in `docs/PRODUCT_FEEDBACK.md`. If Windows: stop and tell Rahul the options (dual-boot Ubuntu, or Lane B per bible §16.6) — do not proceed with TV work until decided. Configure the Amazon Devices Builder Tools MCP server in your coding agent if available; note in product feedback.
2. **Layout** exactly as bible §8. Empty modules get typed shells raising `NotImplementedError`. `tv/` is created in S5 — leave a placeholder README only.
3. **Engine skeleton:** `uv` project in `engine/`, `config.py` (pydantic-settings; the only env reader), typer CLI with commands `analyze | verify | report | synth | eval | schema` as stubs, JSON logging setup, typed exceptions (`DecodeError`, `UnsupportedMediaError`, `VerifierFailedError`, `ProfileError`).
4. **Contracts:** bible §9 verbatim in `domain/models.py` (+ `TrackStats`). Tests: JSON round-trip, `t_end > t_start` validation, tz-aware `generated_at`, alpha/gray in [0,1]. `nostrobe schema` writes `spec/schema/hazardtrack.schema.json`; a test asserts the committed schema equals the generated one.
5. **Profiles & params:** bible §12 as frozen dataclasses + `PARAMS_VERSION` + `params_hash()` (stable SHA-256 of canonical JSON).
6. **Luminance model:**
   - Download ITU-R BT.1702-3 (and -2 for cross-reference) from itu.int. Transcribe the SDR signal-level → screen-luminance relation into `luminance/bt1702_sdr_curve.csv` (header: source, edition, page/table). If the PDF gives a formula rather than a table, implement the formula and generate the CSV from it; state which.
   - `curve.py`: `code10_to_cd_m2(np.ndarray) -> np.ndarray`, monotone, vectorized. Tests: 10-bit 400 → 20.1 ± 0.3 cd/m² (SDR anchor stated in BT.1702-3); the ~160 cd/m² anchor from the document; strict monotonicity; vectorized == scalar.
   - `color.py`: sRGB/BT.709 decode helpers, linearization, CIE 1976 u′v′, red ratio per bible §4 (verify WCAG 2.2 wording first; write the exact definition you implemented into `docs/INTERPRETATIONS.md`).
   - `thr(L_dark) = max(20, L_dark/8)` with a continuity test at 160 and a test that the implied Michelson contrast above 160 equals 1/17.
7. **Decode (`decode/ffmpeg.py`):** `probe(path) -> MediaInfo` (ffprobe JSON; reject non-SDR transfer with `UnsupportedMediaError`); `iter_luma(path, grid=(320,180))` yielding uint8 frames + pts; `iter_rgb(path, grid)` likewise; both stream from a subprocess pipe with bounded memory, kill the process on early exit, raise `DecodeError` with stderr tail on failure. Expose `to_cells(luma_frame) -> cd/m² (90,160)` that linearizes before 2×2 averaging.
8. **Synthetic generator (`synth/generator.py`):** pure numpy → raw frames → ffmpeg encode (H.264, yuv420p, limited range, CRF 10, explicit BT.709 tags). Seeded. Primitives: flat gray clip at a code value; full-frame flash at (rate, ΔL, dark level, duty, duration); regional flash (rect or tile set summing to an area fraction); red/non-red alternation at given chromaticities; moving bar; camera-flash burst; lightning; police lights; isolated 1/2/3 flashes. Each clip writes a sidecar `*.truth.json` (rule-level ground truth: must_fail | must_pass, expected intervals, parameters). Output to `synth_out/` with `HAZARD_` prefix + warning README (bible §14). Add `synth_out/` to `.gitignore`; commit only the manifest.
9. **Decode round-trip tests:** generate flat clips at codes {16, 64, 128, 200, 235} (8-bit), decode, assert recovered code ±1 and cd/m² from the curve. Generate a hard-edged checker clip and assert `to_cells` linear averaging differs from full-resolution linear averaging by < 1 cd/m²; if not, raise grid resolution and record it.
10. Start `docs/FRICTION_LOG.md` (template in pack file 12) and `docs/PRODUCT_FEEDBACK.md`.

## Acceptance gates
- `uv run ruff check && uv run ruff format --check && uv run mypy --strict src && uv run pytest -q` all clean.
- `uv run nostrobe synth --suite smoke` produces ≥ 10 clips with truth sidecars in < 60 s; `ffprobe` shows correct fps/size/BT.709 tags.
- Luminance anchor tests pass and cite the source edition in the CSV header.
- Lane decided and recorded; Vega Virtual Device hello-world ran (Lane A) or the Lane B decision is written in `tasks/todo.md`.
- Report: built / verified (with command output summaries) / deferred.
