Read `CLAUDE.md`, `tasks/lessons.md`, pack files 09–12. Plan first.

## Goal
A submission a judge (or an automated reviewer) can verify in two minutes from the README alone, every number traceable to `eval/RESULTS.md`, and every demo shot recordable.

## Build
1. **README.md (product repo)** — top: one-line pitch, 20-second GIF of the veil timeline (traces/overlay only), **"Runtime hook" section** listing exact files where the required tech is called: `tv/src/player/VegaW3CPlayer.ts` (`@amazon-devices/react-native-w3cmedia`), `tv/src/veil/VeilLayer.tsx`, `infra/template.yaml` (Lambda/S3), and how it runs on the Vega Virtual Device. Then: quickstart (engine, TV app on VVD, AWS deploy), architecture diagram, results headline (copied from RESULTS.md with link), safety disclaimer, prior art (Harding FPA, PEAT, Flikcer, Carreira et al. — what they do and how HazardTrack differs: a portable, verified sidecar format and playback-time veil, not a new detector), license, attribution.
2. **Full self-review** (engineering-workflow Gate 4) across both repos; fix findings. Edge cases: 0-length video, VFR video, 4K input, missing audio, corrupt file, HLS URL in catalog, profile with no events, overlapping unresolved + veiled segments, seek storms on the TV.
3. **Security pass** — no secrets in repo/history (scan), dependency audit (`pip-audit`, `npm audit` — fix highs), S3 policy re-check, input size limits in Lambda.
4. **Docs** — finalize `docs/INTERPRETATIONS.md`, `docs/SAFETY.md` (bible §14 + disclaimer), `docs/ATTRIBUTION.md`, `docs/PRODUCT_FEEDBACK.md` (one section per tool: used for, worked well, needs work, onboarding zero→hello world, would build again Y/N + why), `docs/FRICTION_LOG.md` (≥ 8 real entries, format per pack file 12; dedupe; severity honest).
5. **Feature requests** — 3–5 concrete, each with why + priority (Critical/Important/Nice-to-have), e.g. platform-level metadata text-track support in Vega W3C media if missing, frame-accurate media time API, system-level hazard-track consumption in the Vega player for all apps. Only request things you actually hit.
6. **Demo readiness** — walk `09_DEMO_SCRIPT.md` shot by shot on the deployed build; every shot recordable; numbers on screen match RESULTS.md.
7. **Repo hygiene** — private-repo path: add `testing@devpost.com` and Amazon reviewers listed in the rules as collaborators at submission time (invites expire in 7 days). Public path: license visible in About.
8. Final `nostrobe eval` run; freeze `RESULTS.md`; tag `v1.0.0`.
