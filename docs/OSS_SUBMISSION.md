I published HazardTrack, an open timed-sidecar format and Python reference
library for detecting SDR flash hazards and verifying a playback veil. I
extracted the deterministic detector, solver, verifier, readers/writers, schema,
conformance fixtures and tests into an Apache-2.0 repository, added independent
CI and a portable HTML5 metadata reader, and pinned the product to its release.
This gives publishers and player developers a reusable way to distribute
verified viewing-aid metadata beside video without adopting the TV application
or AWS infrastructure.

The README carries the fixed viewing-aid disclaimer. No medical certification,
Kiro use, cloud benchmark or unmeasured browser/device calibration is claimed.
