# Session 4 — Evaluation harness and the numbers we will quote

Read `CLAUDE.md`, `tasks/lessons.md`. Plan first.

## Goal
One deterministic command, `uv run nostrobe eval`, regenerates `eval/RESULTS.md` with every number the video and Devpost will quote. Nothing in the submission may come from anywhere else.

## Build
1. **Manifest (`eval/manifest.yaml`)** — suites:
   - `boundary`: all S1 boundary pairs × fps set.
   - `shapes`: the S1 shape library with randomized params (seeded, n≈200).
   - `realistic`: hazards composited onto CC-BY footage (`synth/composite_real.py`): camera-flash bursts over a crowd scene, lightning over a landscape, police red/blue over a street, strobe in a club-like dark scene, glitch cuts. Download sources once via a script with checksums; record titles, authors, licenses, URLs in `docs/ATTRIBUTION.md`. Use Blender open movies (e.g. Sintel, Tears of Steel, Big Buck Bunny, Elephants Dream, Spring) — verify each license on the official page before use.
   - `clean`: the unmodified CC-BY films (false-positive control).
2. **Runner (`eval/run_eval.py`, exposed as `nostrobe eval`)** — caches decoded cells by checksum; runs analyze per profile; compares with truth.
3. **Metrics → `eval/RESULTS.md`** (markdown tables + `eval/results.json` machine-readable):
   - Clip-level confusion (must_fail vs must_pass) per profile; **FN count highlighted**.
   - Interval IoU distribution (median, p10).
   - Verifier pass rate after veiling at all offsets; unresolved count with reasons.
   - Viewing cost: veiled fraction of runtime, mean α, mean |ΔL| inside veiled segments.
   - Clean films: `fail` events found (expected 0; if any, include a trace screenshot of the luminance curve and the honest explanation — e.g. a genuine strobe in the film is a true positive, not a false alarm).
   - Speed: × real-time for detect and for full analyze, machine spec.
   - Environment block: engine version, params hash, ffmpeg version, git SHA, seed.
4. **Determinism test** — running eval twice yields byte-identical `results.json` (excluding a single `run_started_at` field).
5. **Optional PEAT cross-check** — if a Windows machine with PEAT is available, run a 20-clip subset, record agreement in a separate table; otherwise the section says "not run".
6. **Headline block** at the top of RESULTS.md: the 4–6 numbers for the video (e.g. "0 missed hazards on N must-fail clips", "100% of veiled segments re-verify under ±X ms", "mean veil strength Y", "Z× real-time").

## Acceptance gates
- `nostrobe eval` twice → identical `results.json`.
- **FN = 0 on must-fail across boundary + shapes + realistic for all profiles.** If not, return to S2/S3 logic; never edit truth to match output.
- Clean-film results explained in prose.
- Quality gates clean.
